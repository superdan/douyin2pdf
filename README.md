# 抖音图文转PDF - Chrome 浏览器插件

在抖音网页版图文（笔记）页面一键提取全部图片（试卷、资料等），本机合成 A4 高清 PDF 并保存。

[![Release](https://img.shields.io/github/v/release/superdan/douyin2pdf)](https://github.com/superdan/douyin2pdf/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 快速下载

到 [Releases 页面](https://github.com/superdan/douyin2pdf/releases/latest) 下载最新的 `douyin2pdf.zip`，解压后按下方步骤安装即可。

## 功能特点

- 一键提取：自动识别笔记里的全部正文图片（自动排除头像、封面、评论图、推荐缩略图）
- 页码勾选：弹窗内缩略图预览，点选保留需要的页
- 本地合成：纯原生 JS 生成 PDF 1.4（图片 DCTEncode 嵌入），零外部依赖，图片不上传任何服务器
- A4 版面：150 DPI 等比排入 A4 竖版，四周留 20pt 边距，可直接打印
- 自定义文件名：自动取笔记标题，可手动修改

## 安装步骤（开发者模式加载）

1. 下载并解压 `douyin2pdf.zip`（或直接使用 `douyin2pdf` 文件夹）
2. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
3. 打开右上角「开发者模式」开关
4. 点击左上角「加载已解压的扩展程序」，选择 `douyin2pdf` 文件夹
5. （建议）点击浏览器工具栏拼图图标，把「抖音图文转PDF」固定到工具栏

## 使用方法

1. Chrome 打开抖音图文页面，例如 `https://www.douyin.com/note/7676078785821540273`
   - 也支持搜索页弹层链接（`douyin.com/search/…?modal_id=…`）：点插件图标会自动跳转到对应笔记页并提取
2. 等笔记图片显示出来后，点击工具栏的插件图标
3. 弹窗会显示识别到的图片数量和缩略图，点击缩略图可取消/恢复选择
4. 确认文件名，点击「生成 PDF」
5. PDF 自动保存到浏览器默认下载目录

## 常见问题

**提示「页面未响应」？**
刷新抖音页面（F5），等图片加载出来后再点插件图标。

**识别的张数不对？**
抖音页面懒加载：滑动查看全部图片后再点插件图标即可识别完整张数；
也可以在弹窗里手动勾选需要的页。

**下载的 PDF 打不开或提示损坏？**
该笔记图片可能有防盗链限制，请确认是在已登录的浏览器里打开的笔记页面。

**图片清晰度？**
使用抖音服务器提供的最高规格图片（约 2000×3000），150 DPI 下打印 A4 清晰度足够。

## 文件结构

```
douyin2pdf/
├── manifest.json      # MV3 插件清单
├── background.js      # 后台：图片下载 + 任务编排
├── content.js         # 页面注入：提取笔记图片链接
├── popup.html/js      # 弹窗界面：预览、勾选、触发生成
├── offscreen.html/js  # 离屏文档：Canvas 图像处理
├── lib_pdf.js         # 纯原生 PDF 1.4 生成器（零依赖）
└── icons/             # 插件图标 16/48/128
```
